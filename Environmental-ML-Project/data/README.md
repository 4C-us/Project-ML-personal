# data

Data files are generated by `notebooks/01_data_preparation.ipynb` and stored in Google Drive (`MyDrive/Environmental-ML-Project/data/`):

- `cocip_europe_YYYYMMDD.parquet`: CoCiP output per day (8-14 Jan 2024)
- `dataset_europe_v1.parquet`: merged dataset with villain labels (263,045 rows, 27 columns, ~31 MB)

They are not committed because of their size.
